About Me

My name is Hailey Anderson. I'm a software engineer with experience in Data, Infrastructure and User Interface based in Providence, RI. My work focuses on designing scalable ETL pipelines and data governance systems that enable smarter decision-making. Recent projects include building automated data infrastructure for cloud operations and analyzing policy data to reveal systemic inequities in immigration systems. Beyond core data work, I'm passionate about technology that serves community. I'm available for:

Data engineering projects — ETL pipelines, data governance, cloud infrastructure Web development services — Building clean, effective websites for nonprofits, small businesses and mission-driven organizations Data analysis — Turning raw data into insights for policy, research, or organizational impact
